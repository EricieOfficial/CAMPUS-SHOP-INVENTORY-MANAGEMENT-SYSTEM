# CAMPUS-SHOP-INVENTORY-MANAGEMENT-SYSTEM
A Java-based application designed to manage campus shop inventory by allowing users to add, view, update, and validate product information, including prices and stock quantities. It demonstrates key Java concepts such as classes, objects, encapsulation, getters and setters.

============= How does the system work? =========================

The Inventory Management System was developed using Java and Object-Oriented Programming principles.

The application allows users to create product objects, store product information, display product details and update existing product information using setter methods.

The system uses encapsulation to protect product attributes and controlled access through getter and setter methods.

Validation was also implemented to prevent invalid entries, such as negative unit prices and negative stock quantities. When an invalid value is entered, the application displays an error message and retains the previous valid value.

The application was tested successfully to demonstrate product creation, displaying product details, updating product attributes and rejecting invalid values.



=============== How to Run the Application ========================

1. Open Eclipse IDE.
2. Open the Inventory Management System project.
3. Locate Main.java.
4. Right-click the file.
5. Select Run As → Java Application.
6. View the application output in the Console.

===================== Demonstration ==============================

The application demonstrates:
- Creation of five product objects.
- Displaying product information.
- Updating product prices and stock quantities.
- Rejecting negative prices and stock quantities.
- Retaining existing values after unsuccessful updates.
